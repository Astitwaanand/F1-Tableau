# F1 source datasets

These five CSV exports were downloaded from the project source workbook `F1 Racing Project Dataset.xlsx` and are used by the Tableau workbook.

- `race_results.csv` — race result and finishing status records.
- `qualifying_results.csv` — qualifying classifications.
- `lap_intelligence.csv` — lap-level timing and race information.
- `circuits.csv` — circuit and host-country reference data.
- `championship_standings.csv` — driver / constructor championship standings.
